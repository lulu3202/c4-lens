# Intent

C4 Lens helps a software builder turn a problem statement into two reviewable C4 diagrams. The target user is a builder who needs a quick architecture conversation, not a modelling platform. V1 delivers a structured draft, keeps facts separate from assumptions, requires human approval, then exports System Context and Container diagrams. Success is a clear, valid diagram pair that can be reviewed in one session. It excludes persistence, accounts, collaboration, component/code diagrams, and autonomous repair.
