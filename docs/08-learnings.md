# Learnings

Intent stayed useful because it made the rejected complexity explicit. Context-before-Behavior avoided inventing runtime parts; Behavior-before-Container made the Streamlit monolith an outcome rather than a default. The Architecture Review Pack replaced overlapping design notes, and skipping a boundary contract was correct because no independently meaningful interface exists.

Proof-before-code paid off twice: it kept CI credential-free and exposed a real inline-SVG rendering defect during the local smoke test. The Anthropic migration exposed a second, more important product correction: a generic “resolve and approve” button was not genuine human review. The final build requires an explicit accept or reject choice for every proposal; correction remains possible through the compact JSON editor. Retain the ordering and one-artifact rule. Simplify only by keeping article assets to verified captures, and treat deployment authentication as an external handoff rather than pretending it happened.
